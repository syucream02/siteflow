# GitHub保存前の点検（2026-09-30）

## 対象と結果
GitHubに送るソース・設定・文書を点検し、APIキー、GitHubトークン、AWSアクセスキー、秘密鍵、認証情報付きURL、個人PCのパスが含まれていないことを確認した。スクリーンショットは画面内の架空データだけで、顧客情報や個人アカウント情報はない。

## 除外したもの
- node_modules：ダウンロードしたライブラリ。package-lock.jsonから復元する。
- dist、.next、.vinext、.wrangler、.sites-runtime：ビルド出力とローカルの実行情報。
- *.tsbuildinfo：生成キャッシュ。元のGit管理対象だったため、新しい履歴では除外。
- .openai/hosting.json：個別のSites識別情報。秘密鍵ではないが、公開不要なのでローカルだけに残す。
- AGENTS.md：ローカルの学習・作業指示。
- .env*、.dev.vars*、秘密鍵形式：今後も誤って追加しないため除外。

## 再現性
個別設定がなくても.openai/hosting.example.jsonで動くようにした。個別設定を除いた確認用コピーで、型検査・業務テスト7件・本番ビルドが成功した。

## Gitの履歴
.gitignoreは、既存のコミットから情報を削除しない。初期コミットに含まれた個別設定、キャッシュ、個人メールアドレスをGitHubへ送らないよう、整理した状態からGitHub用の最初のコミットを作成する。元の履歴はPC内の元のプロジェクトに保持し、点検済みファイルの別コピーで新規のmainを作成して送信する。元のプロジェクトのGit管理領域はこの実行環境では変更できないため、元の履歴やリモート設定は変更していない。コミットのメールアドレスにはGitHubのnoreplyアドレスを使う。
